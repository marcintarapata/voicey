# Voicey

Voicey is a personal, privacy-first desktop dictation tool: press a shortcut,
speak, and get your words where you need them — plus optional screen context
captured and summarized locally. It is being built as a sleek, minimal-friction
spin on [Handy](https://github.com/cjpais/Handy) (MIT), reusing whatever its
base proves worth reusing.

Status: pre-implementation. See [docs/product-brief.md](docs/product-brief.md)
for the product direction and open design decisions.
